# 📄 DocuMatch AI

### Intelligent Document Similarity & Duplicate Finder

DocuMatch AI is a smart web application that helps users identify duplicate and similar documents easily.

## ✨ Features
- 📂 Upload PDF, DOCX and TXT files.
- 🔍 Detect exact duplicate documents.
- 🧠 Identify similar documents.
- 📊 Compare documents side by side.
- 🕸️ Visualize document similarities.
- 🔐 Secure document management.

## 🛠️ Technologies Used
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL

## ⚙️ How It Works
1. Upload documents.
2. Extract and process text.
3. Analyze document similarity.
4. Detect duplicates.
5. Display comparison results.
